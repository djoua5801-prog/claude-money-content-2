## Muster nach Kategorie (eigene Formulierungen für unsere Nische)
| Kategorie | Muster | Beispiel von uns |
|---|---|---|
| Neugier / Widerspruch | Aussage, die erst mal nicht stimmen kann | „Dieses Video ist eigentlich nur eine Textdatei.“ |
| Gegensatz | Zwei kurze Sätze gegeneinander | „Ein Chatbot antwortet. Claude Code arbeitet.“ |
| Konkretes Ergebnis | Zahl + Ergebnis + Einlöse-Versprechen | „Drei Prompts. Eine fertige Website. Ich zeige dir alle drei.“ |
| Einwand umdrehen | Zweifel des Zuschauers aufnehmen | „Du kannst nicht programmieren? Gut.“ |
| Nutzen mit Produktname | Was gebraucht wird + Claude Code | „Drei Dinge, für die Firmen heute schon bezahlen.“ |
| Fehler / Warnung | Häufiger Fehler | „Die meisten schreiben einen einzigen riesigen Prompt.“ |
| Einrichtung | „X Dinge, die du sofort einstellen solltest“ | noch offen (Backlog) |
| Vergleich | A gegen B | noch offen (Backlog) |

## Regeln für uns
1. Hook-Text steht ab dem ersten Bild groß auf dem Schirm (viele schauen ohne Ton).
2. Der erste Satz hat höchstens ~12 Wörter und nennt Thema oder Produkt.
3. Kein Geldbetrag ohne belegtes Fallbeispiel. Keine erfundenen Zahlen.
4. Das Versprechen des Hooks wird im Video sichtbar eingelöst (Beweis-Szene).
5. Spätestens alle ~4–5 Sekunden wechselt das Bild (neue Szene oder Kapitelkarte).
