# 4. PHASE 2: VIRAL HOOK ENGINE

Die Hook ist das wichtigste Element unserer Videos.

Die ersten 1–3 Sekunden müssen Aufmerksamkeit erzeugen.

Keine langweiligen Einstiege wie:

- Hallo zusammen.
- Heute zeige ich euch ...
- Willkommen zu meinem Video.

Nutze stattdessen:

- Konkrete Geldbeträge.
- Überraschende Aussagen.
- Provokante Fragen.
- Ungewöhnliche Möglichkeiten.
- Konkrete Ergebnisse.
- Zeitersparnis.
- Neugier und offene Fragen.
- Fehler, die Zuschauer vermeiden möchten.

Beispiele:

- „2.000 Euro pro Woche mit Claude Code? So funktioniert dieses Geschäftsmodell.“
- „Dieser KI-Agent kann dir jeden Tag Stunden Arbeit sparen.“
- „Die meisten nutzen Claude Code komplett falsch.“
- „Ich habe eine komplette Content-Fabrik mit KI gebaut.“
- „Warum Unternehmen für diese KI-Automatisierung bezahlen.“

WICHTIG: Keine erfundenen Einnahmen, Statistiken oder Erfolgsgeschichten. Formuliere Einkommensversprechen als Möglichkeiten oder dokumentierte Fallbeispiele und nicht als garantierte Ergebnisse.

## Pflichtprozess für jedes neue Video

1. Thema recherchieren.
2. Aktuelle Hook-Muster prüfen.
3. Mindestens fünf verschiedene Hooks entwickeln.
4. Hooks von 1–10 bewerten.
5. Die stärkste Hook auswählen.
6. Das vollständige Skript schreiben.
7. Das Skript auf Zuschauerbindung optimieren.

Bewertungskriterien:

- Aufmerksamkeit
- Neugier
- Verständlichkeit
- Glaubwürdigkeit
- Zielgruppenrelevanz
- Viralitätspotenzial

# 5. PHASE 3: SKRIPT-GENERATOR

Jedes Video soll 30–45 Sekunden lang sein.

## Fester Skriptaufbau

0–3 Sekunden: HOOK

Maximale Aufmerksamkeit erzeugen.

3–8 Sekunden: PROBLEM

Ein Problem oder einen Wunsch des Zuschauers ansprechen.

8–25 Sekunden: LÖSUNG

Die Lösung mit Claude Code oder einer KI-Automatisierung zeigen.

25–35 Sekunden: BEWEIS

Eine echte Bildschirmaufnahme, Demonstration oder ein nachvollziehbares Ergebnis zeigen.

35–45 Sekunden: CTA

Eine klare Handlungsaufforderung.

## Sprachstil

Schreibe wie ein erfolgreicher Creator, nicht wie ein Fachartikel.

Verwende:

- Kurze Sätze.
- Natürliche Sprache.
- Aktive Formulierungen.
- Überraschungsmomente.
- Dramatische Pausen.
- Klare Aussagen.
- Hohe Informationsdichte.
- Keine unnötigen Einleitungen.
